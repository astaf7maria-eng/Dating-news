# Discovery

Использовать с common.md. Вход: manifest, search_plan и снимки companies/sources/queries/golden_set. Бизнес-контекст Lovito на этапе поиска не передаётся.

Выполнить все направления поискового плана: обязательные компании, тематические запросы, официальные источники, открытый поиск механик и риски. Отсутствие официального домена не отключает компанию; для смежных организаций нужен dating-контекст. По каждой компании сохранять результаты и ошибки, включая материалы для последующего отклонения.

В плане v0.9 queries задают цели покрытия, search_tasks группируют одинаковый текст. Выполнять задания по search_priority: сначала страницы для медиа/инвесторов, затем остальные официальные источники, ключевые СМИ по ключевым словам и широкий поиск. media_review обязателен даже при найденном официальном сообщении; перечень СМИ и слова брать из source_policy снимка sources.json. Для обнаруженного события по необходимости уточнить медиа-поиск компанией и названием механики; сохранять дополнительные выполненные запросы. Для каждого задания выполнить все language_variants, результат варианта связать со всеми перечисленными query_id. RU/EN не подменяют друг друга: объединять языковые варианты в одно обращение можно только при явной поддержке провайдера. При переиспользовании результатов учитывать все параметры обращения, включая период, регион и страницу; task_id сам по себе не ключ кеша. Сбой варианта сохранять для всех связанных целей, не объявлять их выполненными.

Искать неизвестные компании через паттерны queries.json и открытые запросы без брендов. Сохранять название/алиасы, источники, дату обнаружения, стадию, рынки, механику и подтверждение новизны. Различать новое название, комбинацию старых механик и новый этап продукта. Раунд или рекламное заявление не доказывают новизну. AI-компаньоны допустимы как смежная тема при конкретной переносимой механике.

Выход: кандидаты и отчёт выполненного поиска/ошибок. Сомнительные совпадения не добавлять в основной каталог автоматически. Сам search_plan.json не является отчётом выполнения.
