# Поиск компаний и новых механик — v0.4

Вход: выбранный период, companies.json, queries.json, sources.json, golden_set.json.

Обязательно искать Tinder, Badoo, Bumble, Hinge, Grindr и все компании golden set. Для смежных компаний соблюдать dating-контекст. Отсутствие официального сайта не отключает поиск. Фиксировать выполненные запросы, результаты и ошибки по каждой обязательной компании. Не ограничивать сохранение будущими десятью пунктами выпуска.

Параллельно искать без названий компаний: новые приложения, модели оплаты за свидание/результат, гарантии, депозиты, AI-интервью, подбор через друзей, ограниченный подбор, офлайн и нишевые сообщества. Открытый запрос новых запусков обязателен наряду с конкретными паттернами: список механик тоже не закрытый.

Для найденного бренда сохранить название/алиасы, первоисточник или отметку о его отсутствии, дату первого обнаружения, стадию, рынки, механику, доказательство её новизны и пользу для Lovito. Различать новое название, новую комбинацию старых механик и новое изменение существующего продукта. Не объявлять механику первой в мире по рекламному заявлению. Раунд сам по себе не доказывает продуктовую новизну.

Сохранять кандидатов до редакционного решения. Не добавлять сомнительную одноимённую компанию в основной каталог автоматически. AI-партнёры без знакомств между реальными людьми — смежная тема; для включения нужна конкретная переносимая механика, а не одно слово dating.

Golden set — эталон тематики и обязательного поиска. Он не разрешает включать старые события вне выбранного live-периода и не заменяет проверку источников. Оригинальные статьи reference-корпуса загружаются и оцениваются отдельно.
