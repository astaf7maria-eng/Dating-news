# Выбор периода

До поиска предложить точное окно последних 7 дней относительно времени запроса по Москве, с временем и исключённым концом. Спросить «Подходит? Да / Нет, укажу свои даты».

При «да» сохранить предложение. При «нет» запросить начало и окончание включительно; проверить даты, при ошибке запросить исправление. Явные даты пользователя принять сразу: оба дня целиком по Москве, длительность любая положительная. Без ответа ждать или завершить без запуска; истечение времени не означает согласия.

Сохранить в manifest границы [start, end), timezone, способ и время подтверждения. Для расписания требуется отдельно настроенная пользователем политика периода. После выбора все этапы используют одно окно. Диалог уже реализован в orchestration/period.py.
