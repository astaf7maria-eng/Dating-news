# Критерии So what для Авито Ловито

Используется внутри совместного написания по write-digest.md и финальной рецензии. Основание — strategic_assessment выбранных событий; повторный полный стратегический анализ корпуса не требуется.

Проверь три вопроса: какую проблему или цель решает конкурент; какой новый сигнал показывает кейс; что следует из него для бизнес-модели, пользовательского опыта или рисков Lovito. Для внешней угрозы разбери логику атакующего или устройства рынка.

Сопоставление кейсов допустимо через related_event_ids. Гипотеза о рыночном сдвиге остаётся интерпретацией; два примера не доказывают распространённость. Существенные ограничения источника и переноса должны быть видны в выводе.

Используй только фиксированный context_bundle. decision_support требует конкретных question_ids; market_watch допускает пустые ID при обоснованной рыночной значимости. Сохраняй статусы утверждений контекста.

Видимые 1–2 предложения объясняют причины и последствия. Перечень экспериментов и метрик без анализа недостаточен. Конкретное действие, пилот или KPI уместны при содержательном основании. Калибровка — so-what-examples.md; факты для нового выпуска подтверждаются его Article.
