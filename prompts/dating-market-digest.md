# Редакционное задание DatingTech

Подготовь Markdown-дайджест для продуктовой и стратегической команды Авито Ловито из корпуса текущего run_dir. Окно, режим, ограничения покрытия и отпечаток бери из editorial/inputs.json, тексты — из editorial/news.json, контекст — из context_bundle.json. Исторические периоды и пути не являются входами нового задания.

Рабочий маршрут: анализ событий → стратегический отбор → совместное написание саммари и So what → отдельная редакционная проверка. Следуй editorial/instructions.md и профильному промпту каждого этапа. Ориентир — editorial/policy.json.target_news_total (по умолчанию 10). Если иначе будут упущены особо важные самостоятельные события, расширь выпуск до editorial/policy.json.max_news_total (не более 13). Сохранить главное важнее краткости; не добирай новости ради количества и не вводи квоты по разделам. Обоснуй расширение в ranking.json.expansion_reason.

При отборе оценивай изменение стратегии, бизнес-модели, механики, поведения, возможностей и рисков. Событие включается при содержательном стратегическом выводе для Lovito; известность компании сама по себе не основание. Подтверждённые результаты сохраняют масштаб, намерение не становится результатом, один кейс не доказывает рыночный тренд.

Контекст Lovito фиксирован пользователем; не перепроверяй PDF и не придумывай возможности продукта. observed_in_test — результат конкретного теста, planned — исторический план, hypothesis — предположение, unresolved — оговорка. Из fake-door не выводить конверсию реальной верификации. Внешние факты подтверждаются Article. Внутренние ID и PDF не выводятся в пост.

Саммари: 2–3 предложения по-русски с изменением, механикой, существенными числами, условиями и стадией. So what: 1–2 предложения о бизнес-логике, рыночном сигнале и последствиях для Lovito. Переиспользуй strategic_assessment; эксперимент или KPI добавляй только при основании. Не копируй функцию конкурента механически и не заменяй анализ общими советами.

Формат локального Markdown задаёт render-digest:

## 💘 DatingTech | Дайджест за {period}

*Ключевые продуктовые и рыночные события периода*

### 1. {Компания} — {оригинальный Title}

🔗 {оригинальный URL}

**Что произошло:** {саммари}

**💡 So what для Ловито:** {стратегический вывод}

Новости идут по приоритету. Оговорки покрытия сохраняются; оценки и причины исключения остаются в служебных файлах. Пользователю передаётся проверенный Markdown. При блокирующей ошибке верни конкретную причину остановки, а не готовый выпуск.
