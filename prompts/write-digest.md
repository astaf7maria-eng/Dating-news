# Написание выпуска

Использовать с common.md. Вход: выбранные события с оценками, доказательства, manifest, context_bundle, editorial_policy, source_policy из снимка sources.json и формат канала. Выход: digest.schema.json.

Использовать русские карточки Event, сформированные при смысловой обработке исходных статей. Article хранится на языке оригинала; evidence_quote в Event остаётся точной цитатой источника. Русский пересказ не подменяет оригинал или подтверждающую цитату. Article, Event и выпуск читать/писать в UTF-8 через общий модуль dating_digest.io.

Заголовок показывает выбранный период по Москве; для полных дней — обе включённые даты. Разделы, порядок, лимит и тексты пустых разделов брать из политики. Сбой сбора обозначать недостатком данных. Одно событие выводить один раз.

Пункт: «N. Компания — изменение», дата публикации, 1–3 факта со стадией, «Для Lovito: …», ссылки. N = display_order; rank сохраняется отдельно. Язык — из бизнес-контекста. Для исследований указывать заказчика и известные ограничения; рекламное заявление не выдавать за независимое доказательство.

So what: обязательно сохранить сигнал рынка и объяснение значения для команды. Использовать предоставленный контекст Lovito только для углубления вывода по уже отобранному событию, без изменения состава, оценок и порядка событий. Проверка актуальности или дополнение сведений Lovito не требуются. Для decision_support связать с вопросом команды; для market_watch объяснить изменение конкуренции или возможностей биздева без искусственного продуктового эксперимента. Действие/гипотезу добавлять только при конкретном обосновании; существенное ограничение доказательств или переноса нельзя опускать. Если действие или ограничение не нужны, пропустить соответствующее поле либо записать null; не заполнять его общей фразой. В видимом блоке «Для Lovito» достаточно 1–2 предложений без перечисления служебных полей. Метрику предлагать по необходимости, эффект не обещать. context_refs сформировать по ID вопросов и утверждений из context_bundle; служебные версии и отпечатки сохранить в digest.
