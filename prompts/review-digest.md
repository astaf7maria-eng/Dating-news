# Независимая проверка

Использовать с common.md. Вход: точная ревизия digest, статьи, события, рейтинг всех кандидатов, manifest, контекст/политики запуска и результаты программных проверок. Выход: review.schema.json с адресом и исправлением каждого замечания.

Проверить факты, даты, стадии, ссылки, новизну, дубли, причины отбора и более сильные пропущенные события. Проверить окно, разделы, лимит, rank/display_order, покрытие и различение пустого раздела со сбоем сбора. Для бизнес-событий допустима стадия not_applicable.

Проверить соблюдение source_policy снимка sources.json: официальные сообщения для медиа/инвесторов искались первыми, ключевые СМИ проверены по ключевым словам даже при найденном первоисточнике. Точные факты сверены с доступным официальным материалом; при его отсутствии зафиксирован пробел. Оценка эффективности не превращена из заявления компании в независимый факт; перепечатка не выдана за независимое подтверждение. Существенные противоречия разобраны, не скрыты выбором удобного источника.

Сверить context_version/context_sha256 с manifest и bundle, ID в context_refs — с предоставленным контекстом. Проверять корректность его использования в so what, сохраняя заданные статусы утверждений; допустимый ID не доказывает смысловую связь. Не перепроверять актуальность контекста Lovito, не дополнять его и не запрашивать обновления. Убедиться, что контекст не изменил поиск, допуск, оценки или порядок новостей. Проверить язык и ограничения канала.

Объяснение значения новости обязательно. Отсутствие действия или ограничения само по себе не ошибка; проверить, что не пропущена существенная оговорка и не добавлено искусственное действие. Видимый блок «Для Lovito» — 1–2 предложения, без обязательного перечисления служебных полей.

Неподтверждённый факт, дубль, существенное искажение даты/стадии, подмена контекста или выдуманное основание рекомендации — blocking. passed допустим без blocking и после успешных обязательных программных проверок. После любого изменения выпуска проверка повторяется для новой ревизии.
