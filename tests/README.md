# Будущая проверка реализации

Фикстуры добавляются по примерам пользователя: статьи RU/EN, даты, дубли и разные стадии запуска. Содержательные проверки: точность извлечения, группировка событий, расчёт рейтинга, блокировка неподтверждённых фактов и восстановление частичной доставки. Контрактные проверки адаптеров выполняются без реальной публикации. Оценку качества top-10 проводить на размеченном наборе с объяснением расхождений.
