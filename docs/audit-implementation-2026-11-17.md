# Исправления сквозного аудита

Архив проверяет Article до записи всего пакета и версионирует изменения метаданных. Невалидные исторические тела не переиспользуются; сохранённые файлы не мигрируются.

Research QA сверяет весь пересобранный план, требует завершённые наблюдения с article_id/target и запрещает blocking по eligible даже в verified_subset. Исторический скрипт .tmp/review-20261109.py, автоматически выставлявший допуск, отключён. Решения рецензент принимает по источникам; CLI не удостоверяет смысл.

Общий промпт сокращён до инвариантов. Исторический запрос отделён от рабочего задания. Саммари и So what пишутся вместе из strategic_assessment; форматы summaries/digest и финальная проверка точной ревизии сохранены.

Неработающие настройки поиска удалены. Порядок обхода определяется source_policy.collection_first_source_ids и приоритетами источников независимо от excluded_domains. Бюджет сбора находится в search_plan.execution_policy.budget. Копия конфигов в плане сохранена для автономного build_followup_query и проверяется на равенство снимкам.

Для новых запусков manifest.initial_status означает состояние при создании. Готовность определяется актуальными QA/Review и квитанциями. Старые manifest и корпуса не переписываются.

Для сохранённого HTML доступен ingestion.save_html_article: при пропущенном Article извлечение возобновляется без сети. Для пронумерованного оригинального текста провайдера используется ingestion.extract_provider_article(pages, metadata, first_line=..., last_line=..., tags=...). Каждый элемент pages — одна исходная страница или продолжение; metadata содержит проверенные title/language/url/source_id/raw_path и даты. Пропуски строк и rewritten summary дают partial; конфликтующие продолжения отклоняются. API сохраняет происхождение и не угадывает дату публикации. Полнота выбранного диапазона требует проверки по источнику.

Сессионные скрипты импорта остаются историей. Для новых материалов использовать общий API; .tmp не является воспроизводимым исполнителем проекта.

После обновления правил старые допуски могут быть stale или blocked. Нельзя просто переписать хеши: нужно проверить изменения, наблюдения и решения, затем повторить qa-research и смысловую QA. Сохранённые корпуса и архивы не изменялись, новая сеть и доставка не выполнялись.

Снижение стоимости LLM — ожидаемый эффект, ещё не измеренный. Проверять его на одинаковом корпусе по полноте событий, фактическим вызовам и качеству выводов.
