# План реализации

Готовы выбор периода, снимки запуска и поисковый план. Каталог и golden set заполнены; полнота реального поиска и качество рейтинга ещё не измерены.

1. Актуализировать спорные планы Gate 2 и разметить эталон; метод сравнения — [контекст](context-integration.md).
2. Подключить поставщика поиска и извлечение текста; сохранить корпус и фактическое покрытие, проверить исторический golden set отдельно от live-периода.
3. Реализовать объединение событий, допуск, рейтинг по конфигу и выпуск; сопоставить с эталоном.
4. Подключить JSON Schema и перекрёстные проверки, затем независимую LLM-рецензию с ограниченным циклом исправлений.
5. Реализовать выбранный канал, экранирование/разбиение и журнал доставки; проверить частичный сбой и неоднозначный ответ API.
6. Настроить возобновление, секреты, журналы и расписание с явно выбранной политикой периода.

Решения для подключения интеграций: поставщики поиска/LLM и бюджет, хост исполнения, канал/адресат и режим доставки, время выпуска, пределы длины и порог достаточного покрытия. Канал и расписание ранее отложены пользователем. Новые зависимости добавлять под выбранную интеграцию.
