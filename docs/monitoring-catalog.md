# Компании и ключевые фразы — каталог v1

Подготовлен 15 ноября 2026, источники проверялись в интернете на этапе исследования каталога. Это каталог для будущего поиска, не дайджест за период. Основные данные: `config/companies.json`, `sources.json`, `queries.json`, `golden_set.json`, `discovery_candidates.json`.

## Обязательный поиск

| Группа | Компании | Правило |
|---|---|---|
| Всегда | Tinder, Badoo, Bumble, Hinge, Grindr | Каждый запуск: проверка источников и RU/EN; уточнения по пробелам. Приоритет запусков, фич и кампаний без произведения на семь разделов. |
| Остальные основные компании голден сета | Match Group, PURE, Liangpei AI, World / World ID | Каждый запуск. World — только в связи с dating; Liangpei искать и без подтверждённого официального домена. |
| Смежные организации из примеров | Freddie / PurposeMed, Ithaca Holdco / Holdings, The Harris Poll | Каждый запуск в контексте Grindr, Bumble и dating-исследований соответственно. Не мониторить всю медицину, инвестиции или все опросы. |

МВД — источник сигналов безопасности, а не dating-компания. Медиа из примеров включены в реестр источников. Badoo добавлен в обязательную пятёрку явно по инструкции пользователя, хотя его нет отдельным пунктом в исходных десяти новостях.

Обязательность касается поиска и сохранения подходящих материалов выбранного периода до редакционного отбора. Она не означает автоматическое место в top-10. Ноль результатов нужно подтвердить выполненными запросами; сбой не считается нулём. Все десять образцов — golden set покрытия и тематики. Их исторические URL перечислены отдельно; полнота поиска по ним ещё не измерена.

## Семь семейств фраз

| Раздел | Русские сигналы | Английские сигналы |
|---|---|---|
| Функции | новая функция, запуск, тест, раскатка, новый рынок | new feature, launch, pilot, rollout, market expansion |
| Монетизация | подписка, тариф, цена, платный пакет, комиссия | subscription, pricing, paid tier, package, fee |
| Безопасность | верификация, проверка документов/лица, антифрод, депозит, гарантия | verification, identity check, fraud, deposit, guarantee |
| AI | ассистент, автозаполнение, подбор, скоринг, модерация | assistant, profile completion, matching, scoring, moderation |
| Новые модели | стартап, новая модель, пилот, раунд, возврат денег | startup, business model, pilot, funding, money-back guarantee |
| Бизнес | финансовые результаты, выручка, платящие, сделка, назначение | earnings, revenue, paying users, acquisition, appoints |
| Маркетинг | рекламная кампания, коллаборация, амбассадор, активация, брендованное исследование | ad campaign, brand campaign, collaboration, ambassador, activation, brand survey |

Семь семейств — словарь классификации и уточнений. Единственный рабочий fast-план v1.1 использует три направления из research_policy: запуски, фичи/тарифы и кампании. Сначала проверяются источники; затем короткие запросы с одним именем/локальным алиасом, квалификатором при неоднозначности и действием. Для Pairs/tapple первичен JA, для Liangpei — ZH; RU/EN остаются в покрытии. Для российских и международных компаний есть открытый поиск интервью и результатов экспериментов вне официальных сайтов. Финансы/риски собираются дополнительным потоком, не требуют слова launch. Текущий маршрут и фильтр — в [event-focused-research.md](event-focused-research.md). Глобальные минус-слова вроде earnings или survey запрещены. Даты берутся только из подтверждённого пользователем периода; провайдерные after/before не подменяют проверку дат статьи.

Примеры:

```text
dating app launches
dating app campaign
Твинби интервью -site:twinby.ru
Hinge interview -site:hinge.co
タップル キャンペーン
良配 相亲 新功能
```

Это примеры формы запроса, не дополнительная обязательная очередь. Фактические формулировки и исключения доменов выбираются из снимка через build_followup_query по сигналу; алиасы и синонимы не объединяются в длинные OR-группы.

## Открытие новых компаний

Независимый от брендов поиск начинается с трёх типов новых событий. Для уточнений по сигналам доступны 14 направлений (без обязательного исполнения каждого в каждом запуске): оплату за свидание; оплату за результат/возврат; депозиты; одного кандидата/ограниченный подбор; AI + человека; друзей/группы; офлайн/заведения; проверку личности/семейного статуса; сегментные тарифы; нишевые сообщества; голос/видео; B2B2C; маркетплейс услуг вокруг свиданий; государственные/некоммерческие сервисы. Дополнительно есть широкий запрос новых запусков без заданной механики, запросы ZH/JA и поиск отраслевых публикаций.

Пилотный поиск без названия бренда дал кандидатов Juno, Within Social, CrowdMatch, Fledge, Overtone. Они сохранены в `discovery_candidates.json` с уровнем подтверждения; не все имеют проверенный первоисточник и не все доказали новую механику. Кандидат с банальной моделью не проходит только за счёт малого размера компании.

Примеры подтверждений от самих сервисов: [Juno](https://hello-juno.com/) описывает разговорный AI-подбор и платное знакомство; [Within Social](https://www.withinsocial.com/about) — подбор через расширенную сеть общих связей; [Breeze](https://www.breeze.social/faq) — оплату за свидание. Заявления сервисов ещё не доказывают эффективность или мировую новизну.

## Источники и ограничения проверки

Приоритет и правила доказательств заданы в source_policy файла sources.json. Сначала проверяются официальные страницы компаний для медиа и инвесторов, затем остальные официальные материалы. После этого обязательно выполняется поиск по ключевым словам в TechCrunch, Global Dating Insights, Dating Industry Insights, 36Kr и «Ведомостях», далее широкий поиск. Перечень СМИ и RU/EN ключевые слова настраиваются в конфиге. Официальное сообщение приоритетно для точных условий, цен, стадии, даты и финансовых показателей; независимый контекст нужен по смыслу. Заявления об эффективности атрибутируются компании, перепечатки не считаются независимой проверкой. При отсутствии официального материала продолжается поиск в СМИ с фиксацией пробела; для внешних рисков подходит первичное сообщение органа или исследователя. Существенные противоречия требуют разбора.

Реестр содержит 34 записи. Официальные точки входа: [Tinder Newsroom](https://www.tinderpressroom.com/), [Hinge Newsroom](https://hinge.co/newsroom), [Match IR](https://ir.mtch.com/investor-relations/overview/default.aspx), [Bumble IR](https://ir.bumble.com/overview/default.aspx), [Grindr News](https://investors.grindr.com/news/default.aspx), [PURE Newsroom](https://press.pure.app/en/), [Mamba Group](https://mamba.group/), [VK пресс-релизы](https://vk.company.ru/ru/press/releases/).

Discovery-источники: [Global Dating Insights](https://www.globaldatinginsights.com/), [Dating Industry Insights](https://www.datingindustryinsights.com/), TechCrunch и 36Kr. [Отраслевой каталог стартапов](https://www.datingindustryinsights.com/directory/startups) даёт дополнительные leads, а не заменяет первоисточники.

Для Liangpei подтверждена публикация [36Kr](https://eu.36kr.com/en/p/3915399664447107); официальный домен пока не назначен. Для Freddie и Ithaca есть первичные сообщения партнёров; отдельные сайты не подставлялись догадкой. Sitch идентифицирован через официальные условия; главная страница недоступна в использованном инструменте. Ссылка Thursday перенаправляется на новый домен; извлечение текста ещё предстоит проверить. Часть медиа из примеров остаётся со статусом user_golden_source, а не проверенной доступности полного текста.

`enabled` означает «участвует в поиске», а не «парсер уже работает». Проверка страницы в веб-инструменте не подтверждает работоспособность будущего адаптера. Следующий этап — исполнение запросов, загрузка статей, измерение покрытия голден сета и настройка бюджета поискового API. Команда `plan-search` пока только создаёт план и матрицу покрытия, без сети и без статей.
