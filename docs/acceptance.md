# Критерии приёмки

- Каталог включает согласованные российские и международные компании, бренды, алиасы и проверенные источники; изменения версионируются.
- Для доступной статьи сохранены текст, дата с точностью, исходный URL, канонический URL и время сбора. Недоступный или неполный текст помечен явно.
- Каждое выбранное событие подтверждено доступным источником; дата публикации не подменяется временем загрузки, стадия запуска не преувеличивается.
- Одно событие занимает одно место. Прежние выпуски учитываются; обновления объясняют добавленный факт.
- Все кандидаты имеют причину включения/отклонения. Рейтинг воспроизводится из оценок и весов, редакционные перестановки объяснены.
- Не более 10 событий; нехватка релевантных событий отражена явно. Каждый so what связан с задачей MVP и отделяет факт от гипотезы.
- Для запроса «за последнюю неделю» первым шагом предлагаются конкретные даты и выбор «да/нет»; при «нет» запрашиваются свои даты. Без ответа запуск не создаётся и сбор не начинается. Явно заданные даты принимаются как выбор пользователя.
- Все новости имеют подтверждённую публикацию в выбранном `[window_start, window_end_exclusive)`; диапазон может отличаться от 7 дней. Введённая дата окончания включается целиком по Москве. Выбор и его время сохраняются. Старые запуски в свежих пересказах без обновления не проходят. Даты без достаточной точности требуют уточнения.
- В выпуске присутствуют все семь разделов. Финансы/сделки/назначения и маркетинг допустимы без продуктовой части. В пустых разделах есть явная отметка; неполное покрытие из-за ошибок не объявляется отсутствием новостей.
- Отбор глобальный; одно событие не повторяется между разделами. Глобальный приоритет и порядок отображения после группировки хранятся раздельно.
- Пост содержит заголовок недели, ранжированные новости, источники, аналитический вывод; ссылки и разметка работают в выбранном канале.
- Проверка ловит дубли, неподтверждённые утверждения, неверные даты/стадии и общие бесполезные so what. Блокирующие ошибки не позволяют отправку.
- Сбой источника виден в отчёте. Повтор запуска и восстановление после частичной доставки не создают повторных сообщений.
- Штатная неделя выполняется по расписанию; ошибки, длительность и затраты доступны ответственному. Секреты отсутствуют в репозитории и артефактах.

Численные пороги качества отбора и покрытия согласуем на эталонных примерах. Будущие тесты должны включать RU/EN, отсутствие даты, частичный текст, одинаковое событие в разных СМИ, новый rollout, мало новостей, ошибку источника и неоднозначный ответ API доставки.
