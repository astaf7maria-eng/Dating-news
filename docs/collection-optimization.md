# Проверка оптимизации поиска

15 ноября 2026; окно **1–14 ноября, Москва**. **Ускорение с сохранённым покрытием не подтверждено.** Один холодный контроль дошёл до первого архива/чернового отчёта за **859,57 с (14:19,57)**. Исправленный отчёт после локальной QA — через **1182,38 с (19:42,38)**: полный результат превысил 15 минут. Второго живого прогона не было.

## Изменения

Рабочий маршрут README использует `plan-search --strategy fast`: **38 коротких запросов** первого прохода, **26 нейтральных официальных входов**, **96 условных уточнений** по пробелам. Это не 134 обязательных сетевых обращения. `--strategy exhaustive` оставлен для локального сравнения. Сохранены 27 компаний/12 обязательных, все языки/алиасы, семь тем, 14 моделей, риски, ZH/JA, порядок newsroom/IR → другие официальные → пять СМИ → открытый поиск. Каталожные ссылки на конкретные статьи World/Harris заменяются нейтральными разделами для обнаружения.

`discovery/session.py` добавляет ключ фактических параметров провайдера, резервирование запросов/URL до отправки, queued/inflight/fetched/failed, redirect/canonical, анализ по SHA-256, свежесть кэша, monotonic-бюджет с резервом сохранения и пакетный UTF-8 JSONL. Нормализация URL и постоянное хранение остаются в существующем ArticleArchive.

Промпт задаёт два прохода, доказательства покрытия, максимум четыре сетевые задачи/две на домен, timeout/повторы/circuit breaker, очередь на дедлайне. По результату контроля добавлены компактные журналы с уникальными call_id/request_key, удержание ответа до подтверждения записи и запрет нового поиска из-за ошибки сохранения. Это **сессионные примитивы и планировщик, не автономный исполнитель**. Конфиги, Lovito/PDF, схемы Article, архив и зависимости не изменялись. Доставки/платного API нет.

## Ограничение проверки и итог

Запись полных поисковых ответов превысила лимит кода инструмента 64 КБ: **34** результата утрачены, восемь поисков повторены для восстановления. Коллизия batch-номера перезаписала диагностику; четыре ответа восстановлены из удержанного ответа без сети. Запись в папку запуска требовала разрешённого выполнения вне файлового sandbox. Эти ошибки относятся к контролю, не объясняют старые 38 минут.

Промпт исправлен по этому опыту. Финальные правки EN-алиаса VK Dating и dating-контекста официальных уточнений также проверены локально; **после исправлений второго живого прогона не было**. Цель «10–15 минут с сохранённым покрытием» остаётся непроверенной.

`python -m unittest discover -s tests -v`: **54 теста прошли** — старый exhaustive-контракт, fast-цели/языки, отсутствие эталонных seeds, конкурентные URL, параметры запросов/страница/окно, canonical, свежесть и резерв бюджета. Локальная проверка не заменяет живой сбор.

Артефакты контроля: `collection_summary.json`, `collection_report.md`, `coverage.json`, `event-comparison.json`, `pending.json`, `rejected_materials.json`, квитанции `article_archive*.json`, `raw/search/`, `raw/fetch-journal.jsonl`, `raw/stage-journal.jsonl`. Прошлый запуск не менялся. Корпус, индекс, article/, data/ и .tmp/ в Git не добавлены.
