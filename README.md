# Dating News Digest

Дайджест российских и международных онлайн-знакомств для disco-команды Lovito и биздева. Целевой результат — до 10 уникальных событий на русском с источниками, приоритетом и значением для команды; разделы и правила заданы в [редакционной политике](config/editorial_policy.json).

**Работает:** выбор периода, фиксация конфигов и построение поискового плана. Поиск, загрузка статей, LLM-редактура, проверка выпуска и доставка ещё не реализованы.

## Запуск

Python 3.11+, внешние пакеты не нужны. PowerShell из корня проекта:

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
$env:PYTHONIOENCODING = 'utf-8'
python -m dating_digest --help
python -m dating_digest init-run --start-date 2026-11-01 --end-date 2026-11-14
# Подставить путь созданного запуска:
python -m dating_digest plan-search --run-dir data/runs/<run_id>
python -m unittest discover -s tests -v
```

Обе даты включаются целиком по Москве. Альтернатива: `init-run --as-of 2026-11-15T12:00:00+03:00` предложит последние 7 дней и запросит «да/нет»; при отказе — свои даты. Без ответа запуск не создаётся. В артефактах окно хранится как `[window_start, window_end_exclusive)`.

`init-run` создаёт манифест v0.5, `context_bundle.json` и снимки семи конфигов в `config_snapshot/`. `plan-search` читает только эти снимки, сверяет SHA-256 и сохраняет `search_plan.json` v0.6 с запросами и ожидаемым покрытием. План не означает выполненный поиск. Повторная запись запрещена. Для старых манифестов v0.3/v0.4 используется текущий каталог с явным предупреждением; для полностью воспроизводимого запуска создайте новый. `--config-dir` выбирает настройки при создании запуска и каталог для старых запусков.

Перед созданием запуска и планированием проверяются ссылки каталогов, обязательные компании, разделы, лимит и веса рейтинга по схемам. JSON публикуется атомарно после полной записи через hard link на том же диске; существующий файл не заменяется. Нужна файловая система с поддержкой hard links (например, NTFS); при ошибке записи итоговый файл не создаётся.

## Где менять правила

| Данные | Источник |
| --- | --- |
| Аудитория, язык, утверждения Gate 2 и вопросы команды | [business_context.json](config/business_context.json) |
| Разделы, допуск, лимит выпуска и so what | [editorial_policy.json](config/editorial_policy.json) |
| Период, веса, параметры интеграций | [pipeline.json](config/pipeline.json) |
| Обязательные компании, источники и поисковые фразы | [companies.json](config/companies.json), [sources.json](config/sources.json), [queries.json](config/queries.json) |
| Исторические примеры покрытия | [golden_set.json](config/golden_set.json) |
| Форматы артефактов | `schemas/` |

Код находится в `src/dating_digest/`: `domain` — период и контекст, `discovery` — план запросов, `orchestration` — диалог выбора периода. Общие инструкции будущих LLM-вызовов — `prompts/common.md`; к ним добавляется только промпт текущего этапа.

Контекст Gate 2 исторический: планы не подтверждают работающие функции. Он дополняет широкий поиск и помогает объяснить пользу новости; допустимы и значимые рыночные события вне roadmap. Подробности и способ калибровки — [интеграция контекста](docs/context-integration.md).

Локальные `data/`, примеры, исходный PDF, секреты и временные файлы исключены из Git. PDF не нужен для запуска; переменные интеграций перечислены в [.env.example](.env.example).
