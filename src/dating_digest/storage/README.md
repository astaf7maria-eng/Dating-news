# Хранилище

Будущие компоненты: json_repository.py, run_repository.py, history.py, delivery_ledger.py. Только UTF-8, атомарные записи, стабильные ID, исходные материалы отдельно от редакционных артефактов. Вначале локальные JSON, при конкурентной эксплуатации — транзакционный журнал в SQLite. Секреты не сохраняются.
