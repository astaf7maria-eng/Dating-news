# 1. Discovery

Реализован plan.py: строит воспроизводимый поисковый план из конфигов и подтверждённого периода. Обязательные компании получают базовые RU/EN запросы; отдельно создаются тематические запросы, поиск по официальным источникам, открытие неизвестных компаний и сигналы риска. План хранит снимок настроек и ожидаемое покрытие, без заявления о выполненном поиске. Исполнение, измерение фактического покрытия и загрузка статей относятся к следующему этапу ingestion.
