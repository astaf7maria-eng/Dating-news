# Запуски

Будущие компоненты: pipeline.py, state.py, retry.py, metrics.py. Планировщик вызывает единый pipeline; run_id идентифицирует попытку, digest_id — выпуск недели, revision — его редакцию. Возобновление начинается с незавершённой стадии. Точное окно, настройки, версии промптов, ошибки и результат каждого шага фиксируются в артефактах запуска.
