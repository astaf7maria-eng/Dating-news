# 2. Ingestion

Будущие компоненты: search.py, fetch.py, extract.py, normalize.py и adapters/. Контракты адаптеров изолируют поставщика поиска и способ загрузки. Выход — article JSON и отчёт покрытия/ошибок. Сохранить оригинал, ссылки, точность даты и статус извлечения; повторная ссылка не создаёт новую статью.
