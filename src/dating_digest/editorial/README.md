# 3. Editorial

Будущие компоненты: cluster.py, eligibility.py, rank.py, select.py, write.py. Вход — статьи, контекст и история выпусков; выход — события, рейтинг с причинами и digest JSON. So what содержит конкретную связь с MVP и проверяемую гипотезу. Весами и порогами управляет config, а не скрытая логика промпта.
