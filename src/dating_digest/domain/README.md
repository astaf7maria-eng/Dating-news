# Общие модели

Будущие модели Article, ProductEvent, Score, Digest, Review, DeliveryReceipt. JSON Schema в schemas/ определяет межмодульный формат; здесь будут перекрёстные правила: согласованность дат/статусов, наличие подтверждений, формула рейтинга, уникальность событий, непрерывная нумерация и соответствие проверки ревизии.
